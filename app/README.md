# 🧠 Keep projects and cards organized

This folder runs WhiteBoard. It holds the board, list, search, editors, reminders, themes, local data, and safe file tools. Labels, dates, and attachments stay with each card.

Use `python app/main.py` from the project root. See [the app guide](../docs/USER_GUIDE.md) and [file guide](../docs/FILES.md).
